## Исправления

1. **Возврат после оплаты при истёкшем входе.** Ранее ссылка на договор показывала пустой кабинет с ошибкой без непосредственной кнопки входа. Теперь открывается форма входа с сохранённым адресом договора и результатом банковского возврата; после входа открывается нужный документ. Адрес возврата ограничен корнем приложения и корректным ID документа: переходы на внешний сайт, API и саму страницу входа запрещены.
2. **Скачивание и сохранение при истёкшем входе.** Ранее Word/TXT открывались прямым переходом, и ошибка могла заменить страницу служебным JSON. Теперь файл запрашивается без ухода со страницы, а ошибка 401 предлагает вход в отдельной вкладке. Несохранённые правки остаются в исходной вкладке; после входа действие можно повторить. Автоматического повторения платных ИИ-операций нет.
3. **Описание состояния.** README и инструкция эквайринга теперь отмечают состоявшиеся реальные платежи и отдельный путь уведомлений. Исторические записи DEMO не выданы за текущую конфигурацию.
