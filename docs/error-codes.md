# Справочник ошибок Criterion

В ответе API поле `error` содержит текст для пользователя, `code` — код обращения, `requestId` — ключ поиска в журнале. У одной операции может быть несколько запросов с общим `operationId`. В закрытом журнале `errorCode` описывает сбой на конкретном этапе, `causeCode` уточняет техническую причину, `upstreamStatus` указывает HTTP-статус ближайшего сервиса. В таблицах приведён смысл публичного сообщения. Формулировка зависит от маршрута. События запуска и технические причины доступны дежурному без отдельного сообщения в браузере.

## Ошибки в браузере

В интерфейсе «Скопировать данные для поддержки» формирует код, время UTC, действие и известный `requestId`. Когда браузер не получил ответ, серверный идентификатор ему неизвестен. Для поиска достаточно времени, действия, окружения и релиза. При обрыве во время оплаты сначала откройте тот же договор и используйте «Проверить оплату». Создание нового заказа или чека при неопределённом результате может привести к повторной оплате.

| Код | Компонент и причина | Публичный смысл | Автоповтор и действие |
| --- | --- | --- | --- |
| `CLIENT_OFFLINE` | Браузер считает сеть отключённой после отказа `fetch` | Проверьте интернет-соединение | Для записи — нет. Восстановить соединение и сверить состояние. |
| `CLIENT_NETWORK_ERROR` | Запрос завершился до получения браузером HTTP-ответа | Не удалось получить ответ сервера | Для записи — нет. Проверить соединение, доступность сайта и состояние исходной операции. |
| `CLIENT_RESPONSE_INVALID` | Браузер получил ответ, но не смог разобрать JSON или дочитать файл | Обновите данные или повторите выгрузку | Безопасно повторить чтение/выгрузку. Для изменения сначала сверить состояние. Передать `X-Request-ID`, если он получен. |
| `UI_EXCEPTION` | Необработанное клиентское исключение | Произошла ошибка интерфейса | Нет. Зафиксировать действие, время и версию приложения, затем обновить страницу с учётом несохранённых правок. |
| `HTTP_ERROR` | Клиент получил HTTP-ошибку с отсутствующим или неизвестным публичным кодом, например страницу ошибки прокси | Запрос не выполнен, доступен безопасный текст ошибки | Для записи — нет. Сверить HTTP-статус, релиз прокси и `requestId`, если он получен. |
| `UNSAVED_CHANGES` | Интерфейс блокирует переход или создание договора при незавершённых правках | Сохраните правки текущего договора | Нет. Сохранить правки и продолжить действие. |

## HTTP и документы

| Код | Компонент и причина | Публичный смысл | Автоповтор | Действие дежурного |
| --- | --- | --- | --- | --- |
| `BAD_REQUEST`, `VALIDATION_ERROR` | API получил некорректный JSON, поля или значения | Исправьте формат или данные | Нет | Сверить метод, схему и ограничения размера. Воспроизводить на синтетическом примере. |
| `PAYLOAD_TOO_LARGE`, `UNSUPPORTED_MEDIA_TYPE`, `METHOD_NOT_ALLOWED` | Размер тела, тип содержимого или метод вне контракта маршрута | Сократите запрос, передайте JSON или выберите поддерживаемый метод | Нет | Сопоставить маршрут, `Content-Type` и метод клиента с обработчиком. |
| `UNAUTHORIZED`, `FORBIDDEN` | Нет действительной сессии, служебного токена, требуемых прав или отклонён Origin | Войдите или проверьте доступ | Нет | Проверить тип клиента, origin и нужный способ авторизации. Подпись банковских уведомлений проверяется отдельно. |
| `PAYMENT_REQUIRED` | Закрытый документ либо исчерпаны включённые ИИ-операции | Для действия требуется оплата или недоступна следующая ИИ-правка | Нет | Уточнить состояние оплаты и остаток ИИ-операций. |
| `NOT_FOUND` | Объект отсутствует в доступной пользователю области | Объект не найден | Нет | Проверить идентификатор в интерфейсе владельца. |
| `CONFLICT` | Конкурентное действие, устаревшая ревизия или неподходящий этап | Обновите документ либо дождитесь завершения действия | Нет | Загрузить текущую версию и статус операции. |
| `RATE_LIMITED` | Достигнут лимит авторизации, письма или оформления оплаты | Повторите действие позже | Только после окна и по правилам операции | Найти `rate_limit.exceeded`, тип ограничения и срок `Retry-After`, если он предоставлен. |
| `UNAVAILABLE`, `REQUEST_TIMEOUT` | Сервис временно недоступен или исчерпан срок запроса | Действие недоступно или результат требуется проверить | Только для безопасного чтения после паузы | Проверить readiness и сохранённое состояние изменения. |
| `INTERNAL_ERROR`, `UNKNOWN` | Непредвиденное исключение API или причина без распознанного технического кода | Для API — общее сообщение об ошибке. `UNKNOWN` используется в диагностике | Нет для изменений | Найти этап и события той же операции. |
| `CLEANUP_FAILED` | Ошибка снятия блокировки документа при завершении обработчика | Записывается отдельно от исходного результата операции | Нет | Проверить `operation.failed` с `stage=cleanup`, состояние блокировки и SQLite. Открыть документ после истечения блокировки. |
| `DOCUMENT_SAVE_FAILED` | Ревизия изменилась параллельно (409) или произошёл сбой записи (500) | Откройте последнюю версию или проверьте, сохранены ли изменения | Нет | Сопоставить `document.revision_save_failed` с событиями SQLite. Проверить ревизию до новой генерации. |

## Оплата и связь с банком

| Код | Компонент и причина | Публичный смысл | Автоповтор | Действие дежурного |
| --- | --- | --- | --- | --- |
| `PAYMENT_ERROR`, `PAYMENT_UNAVAILABLE` | Бизнес-ограничения заказа, настройки терминала, чека, URL или недоступное подключение | Точная причина действия или временная недоступность оплаты | Нет для `Init` | Найти `payment.checkout_started`, проверить конфигурацию, статус и активный заказ. |
| `PAYMENT_CHECK_REQUIRED` | Неизвестен результат `Init` либо у активного заказа отсутствует пригодная ссылка | Состояние уточняется, нужна «Проверить оплату» | Только сверка существующего заказа | Найти `payment.init_outcome_unknown`, затем `payment.status_checked` по `operationId`. |
| `PAYMENT_ACCESS_ERROR` | Завершилась ошибкой выдача доступа при подтверждённой операции | Для клиента статус оплаты уточняется, обработчик уведомления может вернуть 5xx | Разрешены повтор подтверждённого уведомления и сверка | Проверить `payment.access_grant_failed`, откат транзакции и доступ к документу. |
| `BANK_REQUEST_REJECTED` | Банк вернул валидный бизнес-отказ | Параметры отклонены или проверка оплаты не удалась | Нет для повтора исходной записи | Проверить `bankMethod`, старый заказ и результат сверки. Для `Init` обработчики отдельно распознают окончательные отказы. |

В сетевых кодах `GATEWAY_` относится к соединению сайта со шлюзом, `BANK_` — к обращению к банку напрямую или через шлюз. Публичный смысл для всех строк — подтверждение банка получить не удалось, проверьте оплату. `retryable` описывает допустимость нового чтения `CheckOrder` или `GetState`. `Init` и `Cancel` транспорт автоматически не повторяет. Фоновая сверка существующего заказа использует свой ограниченный бюджет.

| Коды | Причина | Повтор чтения по `retryable` | Действие |
| --- | --- | --- | --- |
| `GATEWAY_DNS_ERROR`, `BANK_DNS_ERROR` | Ошибка разрешения имени | Нет | Проверить DNS на отмеченном участке. |
| `GATEWAY_CONNECTION_REFUSED`, `BANK_CONNECTION_REFUSED` | Узел отказал в соединении | Да, с задержкой | Проверить процесс, порт и доступность адреса. |
| `GATEWAY_CONNECT_TIMEOUT`, `BANK_CONNECT_TIMEOUT` | Достигнут таймаут подключения | Да, с задержкой | Сверить DNS, TCP, TLS и `connectionReused`. |
| `GATEWAY_TLS_ERROR`, `BANK_TLS_ERROR` | Проверка TLS или сертификата завершилась ошибкой | Нет | Проверить имя, цепочку, срок сертификата и часы узла. |
| `GATEWAY_TIMEOUT`, `BANK_TIMEOUT` | Исчерпан бюджет ответа | Да, с задержкой | Сопоставить TTFB, чтение ответа и остаток общего дедлайна. |
| `GATEWAY_HTTP_ERROR`, `BANK_HTTP_ERROR` | Соседний сервис вернул ошибочный HTTP-статус | При известном 408, 429, 502, 503, 504 | Определить, кому принадлежит `upstreamStatus`. При пересылке ошибки банку нельзя приписывать HTTP-статус шлюза. |
| `GATEWAY_RESPONSE_INVALID`, `BANK_RESPONSE_INVALID` | Некорректный JSON, формат или реквизиты ответа | Нет | Проверить совместимость протокола и текущий заказ. |
| `GATEWAY_RESPONSE_INTERRUPTED`, `BANK_RESPONSE_INTERRUPTED` | Соединение оборвалось при получении ответа | Да, с задержкой | Сверить журналы двух сторон по идентификаторам и время чтения. |
| `GATEWAY_NETWORK_ERROR`, `BANK_NETWORK_ERROR` | Причина сетевого сбоя осталась неопределённой | Нет | Проверить `stage`, `causeCode` и другие наблюдения на этом участке. |

## Почта

При восстановлении доступа публичный ответ нейтрален независимо от существования адреса и конкретного исхода отправки. `mail.provider_accepted` с идентификатором Resend подтверждает приём сообщения провайдером. Сервер не повторяет отправку автоматически.

| Код | Компонент и причина | Публичный смысл | Действие дежурного |
| --- | --- | --- | --- |
| `MAIL_CONFIG_INVALID` | Не прошла проверка настроек Resend, отправителя, обратного адреса или публичного URL | Письма временно недоступны или показан нейтральный ответ | Проверить настройки и подтверждение домена у провайдера. |
| `MAIL_PROVIDER_REJECTED` | Resend вернул явный отказ 4xx, кроме 408/409 | Отправку подтвердить не удалось или показан нейтральный ответ | По `upstreamStatus` проверить права, отправителя и лимиты. Токен этой попытки аннулируется при сохранении отказа. |
| `MAIL_OUTCOME_UNKNOWN` | Сеть, таймаут, неоднозначный HTTP-ответ или отсутствует валидный ID сообщения | Отправка не подтверждена, письмо может прийти | Проверить состояние попытки и кабинет Resend до новой отправки. |
| `MAIL_SEND_FAILED` | Внутренняя стадия выпуска ссылки или отправки не завершилась | Отправку подтвердить не удалось | Искать предшествующее событие по `operationId`, проверить SQLite и журнал почты. |

## ИИ и обработка ПДн

Сервис не повторяет генерацию и восстановление данных автоматически. Для ИИ и ПДн сначала проверьте текущую ревизию и категорию отказа. Синтетического примера достаточно для воспроизведения. Общий публичный смысл ошибок `PII_*` в этом разделе — обработка ПДн остановлена, результат не сохранён.

| Код | Компонент и причина | Публичный смысл | Действие дежурного |
| --- | --- | --- | --- |
| `AI_CONFIG_INVALID`, `AI_AUTH_FAILED` | Ключ модели отсутствует или провайдер ответил 401/403 | ИИ не подключён или администратору требуется проверить доступ | Проверить наличие секрета и разрешение проекта на модель. |
| `AI_RATE_LIMITED`, `AI_PROVIDER_ERROR` | Провайдер ответил 429 или другим неуспешным HTTP-статусом | Лимит исчерпан или сервис ИИ временно недоступен | Проверить `upstreamStatus`, квоты и состояние сервиса. |
| `AI_NETWORK_ERROR`, `AI_TIMEOUT` | Ошибка исходящего соединения или таймаут ответа модели | ИИ недоступен или ответ не получен вовремя | Сверить `durationMs`, сеть и настройки таймаута. |
| `AI_OUTPUT_TRUNCATED` | Ответ оборвался по лимиту длины | Сократите дополнительные материалы | Сверить `finishReason=length` и размеры на синтетическом примере. |
| `AI_RESPONSE_INVALID`, `AI_SCHEMA_VALIDATION_FAILED` | Повреждён ответ или JSON, либо поля результата расходятся со схемой | ИИ вернул ответ неподходящего формата | Сверить `ai.request_failed` с `ai.response_validation_failed`, версию модели и схему действия. |
| `AI_DOCUMENT_STRUCTURE_INVALID` | Изменились структура или идентификаторы разделов шаблона | Исходный документ сохранён | Проверить версию шаблона и проверку структуры. |
| `PII_CONFIG_INVALID`, `PII_TIMEOUT`, `PII_HTTP_ERROR` | Настройки детектора, таймаут запроса, отказ HTTP или сетевой сбой | Обработка ПДн остановлена | Проверить `/api/health/ready`, `stage`, `upstreamStatus`, адрес частного детектора и доступ процесса. |
| `PII_RESPONSE_TOO_LARGE`, `PII_RESPONSE_INVALID`, `PII_SPAN_INVALID` | Ответ детектора превышает лимит, нарушает контракт либо содержит некорректные диапазоны | Обработка ПДн остановлена | Сверить профиль, единицы UTF-16, границы и размер ответа на тестовых данных. |
| `PII_INPUT_LIMIT`, `PII_RESERVED_MARKER` | Превышен лимит структуры/объёма входа или обнаружено служебное обозначение | Обработка ПДн остановлена | Сократить тестовый вход, проверить источник маркера и сериализацию. |
| `PII_ANONYMIZATION_FAILED` | Нарушена целостность текста, структуры или операции замены | Обработка ПДн остановлена | Найти `pii.stage_failed`, сверить `stage` и воспроизвести замену локально. |
| `PII_RESTORE_FAILED`, `AI_PII_RESTORE_FAILED` | Модуль ПДн не смог восстановить результат, в том числе из-за неизвестного или изменённого маркера. Второй код оборачивает отказ на выходе модели | Результат обработки ПДн не сохранён | Проверить `pii_restoration` и `ai.request_failed`, затем локальный цикл замены и восстановления. |

Прежние сборки использовали `AI_NOT_CONFIGURED`, `AI_UNAVAILABLE`, `AI_INVALID_RESPONSE`, `PRIVACY_ERROR`. Эти имена сохранены в перечне допустимых журнальных кодов. При разборе старой версии используйте тот же порядок проверки конфигурации ИИ, доступности модели, формата ответа и детектора соответственно. Автоповтор для этих случаев не предусмотрен.

## SQLite и файловая система

Для ошибок доступа к БД публичный смысл — операцию с базой выполнить не удалось. `DB_BUSY` и `DB_LOCKED` могут возвращаться как 503, остальные ошибки этого класса — как 500. Более конкретная ошибка сохранения договора, отправки письма или оплаты может оборачивать исходную ошибку БД. В журнале найдите `database.operation_failed` и поля `operation`, `causeCode`, `sqliteResultCode`, `rolledBack`, `rollbackFailed`. Автоповтор финансовой записи или генерации по одному коду SQLite исключён. У драйвера уже есть ожидание блокировки до пяти секунд.

| Код приложения | Технические причины | Что означает и как действовать |
| --- | --- | --- |
| `DB_BUSY` | `SQLITE_BUSY`, `SQLITE_BUSY_RECOVERY`, `SQLITE_BUSY_SNAPSHOT`, `SQLITE_BUSY_TIMEOUT` | Другой участник удерживает ресурс. Проверить нагрузку, другие экземпляры и `busyTimeoutElapsed`. Безопасное чтение можно повторить с паузой. |
| `DB_LOCKED` | `SQLITE_LOCKED`, `SQLITE_LOCKED_SHAREDCACHE` | Конфликт блокировок соединения или общей таблицы. Проверить незавершённые транзакции и параллельные операции. |
| `DB_READONLY` | `SQLITE_READONLY`, `SQLITE_READONLY_CANTLOCK`, `SQLITE_READONLY_DBMOVED`, `EROFS` | Запись недоступна. Сверить `DATABASE_PATH`, монтирование и доступ процесса к каталогу, файлу, WAL/SHM. |
| `DB_FULL` | `SQLITE_FULL`, `ENOSPC` | Недостаточно места или исчерпана квота. Сверить `storage.health`, свободные байты, inode, WAL и квоту конкретного тома. |
| `DB_PERMISSION_DENIED` | `SQLITE_PERM`, `SQLITE_AUTH`, `EPERM`, `EACCES` | Операция запрещена ОС/SQLite. Сверить UID, GID, владельца и права тома с entrypoint. |
| `DB_IO_ERROR` | `SQLITE_IOERR`, `SQLITE_CANTOPEN`, `EIO` | Ошибка ввода-вывода или открытия файла. Проверить путь, монтирование и состояние диска у платформы. |
| `DB_CORRUPT` | `SQLITE_CORRUPT`, `SQLITE_NOTADB` | Нарушена целостность либо файл другого формата. Согласовать остановку записи, сохранить исходный том и отдельно проверить восстановление копии. |
| `DB_TRANSACTION_FAILED`, `DATABASE_ERROR` | Не классифицирован отказ транзакции, `SQLITE_CONSTRAINT`, `ERR_SQLITE_ERROR` или иной код драйвера | Проверить операцию, первичную причину, результат отката и ограничения схемы. Повторять изменение только после сверки фактического состояния. |

## Запуск контейнера

Эти коды видны у `startup.failed` до готовности сервиса. Публичного ответа от неработающего экземпляра может не быть. Обычный автоматический перезапуск сохранит ошибку конфигурации, пока значение или образ остаются прежними.

| Код | Компонент и причина | Действие дежурного |
| --- | --- | --- |
| `PII_TOKEN_CONFIG` | Супервизор отклонил формат `PII_ANALYZER_TOKEN` | Сверить установку единого секрета длиной 32–256 печатных ASCII-символов без пробелов у обоих процессов. |
| `PII_URL_CONFIG` | Адрес детектора не соответствует одному контейнеру | Сверить `PII_ANALYZER_URL` с `http://127.0.0.1:8100/analyze` или использовать штатное значение. |
| `PORT_CONFIG` | Некорректен порт сайта или указан зарезервированный порт детектора 8100 | Указать числовой порт сайта 1–65535, согласованный с маршрутизацией платформы. |
| `HEALTH_PATH_CONFIG` | `SITE_HEALTH_PATH` имеет неподдерживаемую форму | Сверить локальный путь с разрешённым маршрутом и конфигурацией проб. |
| `SITE_COMMAND_CONFIG` | Не передана команда процесса сайта после разделителя `--` | Сверить `ENTRYPOINT`/`CMD` с Dockerfile этой версии. |

## Низкоуровневые причины

Причины из таблицы доступны как `causeCode` либо как `errorCode` при диагностике запуска, хранения и транспорта. Публичное сообщение и право повтора задаёт внешний код приложения. Наличие технического кода само по себе не разрешает переотправку операции.

| Коды | Компонент и действие |
| --- | --- |
| `ENOENT`, `ENOTDIR`, `ELOOP` | ОС не находит путь, встречает обычный файл вместо каталога или цикл символических ссылок. Сверить настроенный путь и mount. |
| `EMFILE`, `ENFILE`, `EBUSY` | Исчерпан лимит открытых дескрипторов или ресурс занят. Проверить показатели процесса и конкурирующие операции. |
| `ENOTFOUND`, `EAI_AGAIN`, `ECONNREFUSED`, `ENETUNREACH`, `EHOSTUNREACH` | Сетевое имя не разрешено, соединение отклонено или отсутствует маршрут. Проверить DNS и исходящую сеть именно у компонента, записавшего ошибку. |
| `ECONNRESET`, `ECONNABORTED`, `EPIPE`, `UND_ERR_SOCKET` | Соединение закрыто или сокет оборван. Проверить передачу тела и длительности соседнего сервиса. |
| `ABORT_ERR`, `ETIMEDOUT`, `UND_ERR_CONNECT_TIMEOUT`, `UND_ERR_HEADERS_TIMEOUT`, `UND_ERR_BODY_TIMEOUT` | Запрос отменён или просрочены подключение, заголовки, тело. Проверить бюджет всего запроса и его фазы. |
| `CERT_HAS_EXPIRED`, `DEPTH_ZERO_SELF_SIGNED_CERT`, `SELF_SIGNED_CERT_IN_CHAIN`, `ERR_TLS_CERT_ALTNAME_INVALID`, `UNABLE_TO_VERIFY_LEAF_SIGNATURE`, `UNABLE_TO_GET_ISSUER_CERT_LOCALLY` | Проверка сертификата TLS завершилась ошибкой. Проверить часы, имя, срок и доверенную цепочку узла. |

Порядок действий по конкретным симптомам приведён в [инструкции дежурного](troubleshooting.md).
